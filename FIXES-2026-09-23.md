# Local Map Upgrade 1.7.104.0 - stability and CTD hardening

This source targets **Skyrim 1.7.104.0 only**.

## CTD / runtime hardening

- Shader compilation now exits safely when `D3DCompile` fails instead of continuing with a null shader blob.
- Temporary D3D shader blobs and generated pixel shaders have explicit lifetime handling.
- Local-map ray picking validates the renderer/camera path, loaded cell data, cell 3D state, TES/grid state, LOD children and raycast results before dereferencing them.
- Marker confirmation callbacks reacquire the current MapMenu instead of retaining a raw LocalMapMenu pointer across an asynchronous message box.
- Runtime CALL hook sites are checked before patching so an unexpected executable layout fails safely rather than applying a bad trampoline.
- Console-command lookup, UI access, shader accumulator state and other singleton-dependent paths are guarded.
- Infinity UI message handling performs defensive pointer validation and does not intentionally terminate Skyrim merely because the optional integration endpoint is unavailable.
- Detect Life / Detect Dead / Aura Whisper ranges are read from active player effects. The old global shader-effect detach/update hooks that could clear unrelated detection state were removed.
- The plugin rejects unsupported Skyrim runtimes; the hook/offset set is for 1.7.104.0.

## Logic / performance

- Marker placement debounce state is actually consulted.
- Settings INIs are parsed once per file per reload rather than once per individual setting.
- Native enemy handles use a hash set for membership checks.
- Undead race keyword classification is cached.
- Marker raycasts stop searching once a usable hit is found.

## Build / release

- CommonLibSSE-NG is pinned to version 9.0.1 / commit `736dc64094e59232abfbcdf796cd0a063e136ec6`.
- The local vcpkg overlay fixes CommonLibSSE-NG's exported DirectXTK dependency metadata for consumers.
- `Build-1.7.104.0.cmd` supports current Visual Studio toolchains, CMake, Ninja and an isolated local vcpkg checkout.
- `/experimental:deterministic`, `/pathmap`, `/Brepro` and `/PDBALTPATH` are used to reduce leakage of local source paths in release artifacts.
- `tools/build-package.cjs` rebuilds and validates the distributable package from tracked source assets rather than relying on an old checked-in package tree.

## Verification status

- The final source has completed the Windows build pipeline successfully.
- MCM package generation validates all 11 settings/defaults and the ESL quest/VMAD/player alias/PEX/SEQ structure.
- The current build was reported loading and working in Skyrim 1.7.104.0 on 2026-09-23.
- This is still native SKSE/engine-hooking code; no statement can guarantee that every third-party mod combination is CTD-free.
